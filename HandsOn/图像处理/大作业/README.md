# 人脸表情情绪识别系统

一个基于深度学习的人脸表情情绪识别系统，支持图片和视频分析，实时检测7种基本情绪。

## ✨ 功能特性

- 🖼️ **图片识别**：上传图片自动识别人脸表情
- 🎥 **视频处理**：支持视频文件逐帧分析
- 📹 **实时检测**：摄像头实时人脸表情识别
- 📊 **数据统计**：情绪分布图表和历史记录
- 💾 **数据存储**：SQLite数据库保存处理结果
- 🎨 **可视化标注**：彩色框标注不同情绪

## 📋 支持的情绪类别

1. 😠 愤怒 (Angry)
2. 🤢 厌恶 (Disgust)
3. 😨 恐惧 (Fear)
4. 😊 开心 (Happy)
5. 😢 伤心 (Sad)
6. 😲 惊讶 (Surprise)
7. 😐 中性 (Neutral)
