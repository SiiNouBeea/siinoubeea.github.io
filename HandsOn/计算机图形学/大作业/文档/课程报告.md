# WebGL三维场景渲染器课程设计报告

## i. 系统实现功能详细描述

### 1. 项目概述

本项目是一个基于WebGL和Three.js的专业级三维场景渲染器，提供完整的3D场景创建、编辑和管理功能。系统采用模块化架构设计，围绕"情感主题"构建，支持用户创建个性化的三维场景。

### 2. 核心功能模块

#### 2.1 用户界面系统

- **现代化深色主题界面**：采用响应式设计，适配不同屏幕尺寸
- **直观的控件布局**：左侧功能面板、中央渲染区域、右侧信息面板
- **实时状态反馈**：底部状态栏显示FPS、模型数量、相机模式等实时信息
- **模态对话框系统**：用于参数配置和文件选择

#### 2.2 场景管理系统

- **完整的场景生命周期管理**：新建、保存、加载场景
- **场景文件持久化**：JSON格式存储，支持版本控制
- **自动保存功能**：防止数据丢失
- **场景模板支持**：提供预设场景配置

#### 2.3 光源与光照系统

- **多类型光源支持**：
  - 环境光：提供基础全局照明
  - 方向光：模拟太阳光，产生方向性阴影
  - 点光源：全向发光，距离衰减
  - 聚光灯：锥形光照区域
  - 面光源：矩形区域柔和照明
- **光影叠加效果**：正确配置多个光源的自然叠加
- **阴影系统**：高质量阴影贴图，支持动态阴影

#### 2.4 相机控制系统

- **多模式相机控制**：
  - 轨道控制：围绕目标点旋转、缩放和平移
  - 穿梭无人机模式：WASD移动，鼠标控制视角，水平仪限制
  - 第一人称模式：沉浸式场景浏览
- **平滑相机切换**：模式间流畅过渡动画
- **智能视角控制**：自动居中、包围盒计算

#### 2.5 模型管理系统

- **基础几何体创建**：立方体、球体、圆柱体等8种基本形状
- **外部模型加载**：支持OBJ、GLTF、GLB、FBX格式
- **模型变换操作**：位置、旋转、缩放实时调整
- **材质系统**：支持Basic、Lambert、Phong、Standard材质
- **纹理映射**：颜色纹理、法线贴图支持

#### 2.6 交互系统

- **智能选择机制**：鼠标点击选择，射线投射检测
- **3D拖拽功能**：平面约束的精确拖拽移动
- **快捷键支持**：删除、复制、锁定选择等操作
- **悬停效果**：视觉反馈增强用户体验

#### 2.7 环境管理系统

- **天空盒系统**：等距柱状投影天空纹理
- **地面纹理**：可配置地面材质和颜色
- **雾效支持**：大气透视效果增强场景深度

#### 2.8 文件管理系统

- **场景文件操作**：保存、加载、导出场景配置
- **图像导出**：PNG格式高质量截图
- **自动匹配机制**：智能定位外部模型文件
- **模板系统**：预设场景快速生成

#### 1. 主程序入口（main.js）

```javascript
class WebGLEditor {
    constructor() {
        // 初始化各管理器实例
        this.sceneManager = new SceneManager('renderCanvas');
        this.lightManager = new LightManager(this.sceneManager);
        this.cameraManager = new CameraManager(this.sceneManager);
        this.modelManager = new ModelManager(this.sceneManager);
        this.uiManager = new UIManager(this);
        this.fileManager = new FileManager(this);
        this.interactionManager = new InteractionManager(this.sceneManager, this);
  
        // 性能统计
        this.clock = new THREE.Clock();
        this.fps = 0;
        this.frameCount = 0;
        this.lastTime = 0;
    }
  
    async init() {
        // 显示加载界面
        this.showLoadingOverlay('初始化场景...');
  
        try {
            // 按顺序初始化各系统
            await this.sceneManager.init();
            await this.lightManager.init();
            await this.cameraManager.init();
            await this.modelManager.init();
            await this.uiManager.init();
            await this.interactionManager.init();
      
            // 设置默认场景
            await this.setupDefaultScene();
      
            // 启动渲染循环
            this.animate();
      
        } catch (error) {
            this.showError(`初始化失败: ${error.message}`);
        } finally {
            this.hideLoadingOverlay();
        }
    }
  
    animate() {
        requestAnimationFrame(() => this.animate());
  
        const deltaTime = this.clock.getDelta();
        const currentTime = performance.now();
  
        // 更新FPS计数
        this.frameCount++;
        if (currentTime >= this.lastTime + 1000) {
            this.fps = Math.round((this.frameCount * 1000) / (currentTime - this.lastTime));
            this.frameCount = 0;
            this.lastTime = currentTime;
        }
  
        // 更新各系统状态
        this.cameraManager.update(deltaTime);
        this.interactionManager.update(deltaTime);
  
        // 渲染场景
        this.sceneManager.render();
  
        // 更新UI状态
        this.updateStatusBar();
    }
}
```

#### 2. 场景生成器核心代码（scene-generator.js）

```javascript
class SceneGenerator {
    async generateInitialScene() {
        this.showLoading('生成场景中...');
  
        try {
            // 清空当前场景
            await this.modelManager.clearAllModels();
            await this.lightManager.clearAllLights();
      
            // 创建多层次光照系统
            this.setupLighting();
      
            // 加载中心模型
            await this.loadCenterModels();
      
            // 生成环境树木
            await this.generateTrees();
      
            // 设置相机视角
            this.setupCamera();
      
            this.showNotification('场景生成完成', 'info');
      
        } catch (error) {
            this.showError(`场景生成失败: ${error.message}`);
        } finally {
            this.hideLoading();
        }
    }
  
    async generateTrees() {
        const treeCount = 500;
        const trees = [];
  
        for (let i = 0; i < treeCount; i++) {
            // 基于种子的确定性随机分布
            const random = this.seededRandom(this.treeSeed + i);
            const angle = random * Math.PI * 2;
            const radius = 10 + random * 70; // 10-80单位半径
      
            // 极坐标转直角坐标
            const x = Math.cos(angle) * radius;
            const z = Math.sin(angle) * radius;
            const scale = 5 + random * 20; // 5-25倍缩放
      
            try {
                // 尝试加载OBJ树木模型
                const tree = await this.loadOBJModel('./models/tree.obj', {
                    position: { x, y: 0, z },
                    scale: { x: scale, y: scale, z: scale },
                    color: new THREE.Color(0.2 + random * 0.3, 0.4 + random * 0.4, 0.1 + random * 0.2)
                });
                trees.push(tree);
            } catch (error) {
                // 降级使用圆锥体作为树木
                const tree = this.modelManager.addPrimitive('cone', {
                    position: { x, y: 0, z },
                    scale: { x: scale * 0.5, y: scale, z: scale * 0.5 },
                    color: new THREE.Color(0.2, 0.6, 0.1)
                });
                trees.push(tree);
            }
        }
  
        return trees;
    }
}
```

#### 3. 相机控制系统核心代码（camera-manager.js）

```javascript
class CameraManager {
    updateDroneControls(deltaTime) {
        if (this.currentMode !== 'drone') return;
  
        const moveSpeed = this.droneControls.moveSpeed * deltaTime;
        const camera = this.sceneManager.camera;
  
        // 基于相机朝向计算移动方向
        const forward = new THREE.Vector3();
        camera.getWorldDirection(forward);
        forward.y = 0; // 保持水平移动
        forward.normalize();
  
        const right = new THREE.Vector3();
        right.crossVectors(forward, new THREE.Vector3(0, 1, 0));
  
        // 处理键盘输入
        if (this.droneControls.keys.KeyW) {
            camera.position.addScaledVector(forward, moveSpeed);
        }
        if (this.droneControls.keys.KeyS) {
            camera.position.addScaledVector(forward, -moveSpeed);
        }
        if (this.droneControls.keys.KeyA) {
            camera.position.addScaledVector(right, -moveSpeed);
        }
        if (this.droneControls.keys.KeyD) {
            camera.position.addScaledVector(right, moveSpeed);
        }
        if (this.droneControls.keys.KeyE) {
            camera.position.y += moveSpeed;
        }
        if (this.droneControls.keys.KeyQ) {
            camera.position.y -= moveSpeed;
        }
  
        // 水平仪限制：保持相机不低于地面
        camera.position.y = Math.max(camera.position.y, 0.5);
    }
  
    handleFirstPersonMouseMove(event) {
        if (!this.firstPersonControls.mouseDown) return;
  
        const movementX = event.movementX || event.mozMovementX || event.webkitMovementX || 0;
        const movementY = event.movementY || event.mozMovementY || event.webkitMovementY || 0;
  
        // 更新相机旋转
        this.firstPersonControls.yaw -= movementX * 0.002;
        this.firstPersonControls.pitch -= movementY * 0.002;
  
        // 限制垂直视角范围
        this.firstPersonControls.pitch = Math.max(
            -Math.PI / 2, 
            Math.min(Math.PI / 2, this.firstPersonControls.pitch)
        );
  
        // 应用旋转到相机
        const camera = this.sceneManager.camera;
        camera.rotation.order = 'YXZ';
        camera.rotation.y = this.firstPersonControls.yaw;
        camera.rotation.x = this.firstPersonControls.pitch;
    }
}
```

#### 4. 交互系统核心代码（interaction-manager.js）

```javascript
class InteractionManager {
    startDragging(object, intersectionPoint) {
        this.draggingObject = object;
        this.dragStartPoint = intersectionPoint.clone();
        this.dragOffset = new THREE.Vector3();
  
        // 计算对象中心到交点的偏移
        object.getWorldPosition(this.dragOffset);
        this.dragOffset.sub(intersectionPoint);
  
        // 创建拖拽平面（基于地面或相机视角）
        this.dragPlane.setFromNormalAndCoplanarPoint(
            new THREE.Vector3(0, 1, 0), 
            intersectionPoint
        );
  
        // 禁用轨道控制以免冲突
        this.sceneManager.orbitControls.enabled = false;
  
        // 更新光标状态
        document.body.style.cursor = 'grabbing';
    }
  
    updateDragging() {
        if (!this.draggingObject) return;
  
        // 从鼠标位置创建射线
        const raycaster = new THREE.Raycaster();
        raycaster.setFromCamera(this.mouse, this.sceneManager.camera);
  
        // 计算射线与拖拽平面的交点
        const intersectionPoint = new THREE.Vector3();
        raycaster.ray.intersectPlane(this.dragPlane, intersectionPoint);
  
        if (intersectionPoint) {
            // 应用偏移量得到最终位置
            intersectionPoint.add(this.dragOffset);
      
            // 更新对象位置
            this.draggingObject.position.copy(intersectionPoint);
      
            // 通知UI更新模型信息
            if (this.editor.getSelectedModel() === this.draggingObject) {
                this.editor.showSelectedModelInfo(this.draggingObject);
            }
        }
    }
  
    getIntersects() {
        const raycaster = new THREE.Raycaster();
        raycaster.setFromCamera(this.mouse, this.sceneManager.camera);
  
        // 只与可交互对象求交
        const interactableObjects = this.sceneManager.scene.children.filter(child => {
            return child.userData && child.userData.selectable !== false;
        });
  
        return raycaster.intersectObjects(interactableObjects, true);
    }
}
```
