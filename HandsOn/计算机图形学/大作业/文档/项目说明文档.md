# WebGL三维场景渲染器 - 项目说明文档

## 1. 项目概述

### 1.1 项目简介

WebGL三维场景渲染器是一个基于现代Web技术构建的专业级3D场景编辑器。采用**Three.js r128**作为图形引擎，使用**原生JavaScript ES6+**开发，无需任何构建工具即可运行。系统围绕"情感主题"设计，支持创建、编辑和管理复杂三维场景，内置程序化场景生成功能，可一键生成500棵树木的森林场景。

### 1.2 主要特性

* **完整3D编辑功能**: 模型加载、变换、材质编辑、光源管理、相机控制
* **模块化架构**: 10个独立管理器，职责清晰，易于扩展
* **实时交互**: 60FPS流畅渲染，支持模型拖拽、多模式相机
* **数据持久化**: 场景保存/加载，JSON格式，版本兼容
* **智能容错**: 模型加载失败自动降级为占位符，应用不崩溃
* **现代化UI**: 深色主题，响应式设计，实时状态反馈

## 3. 安装与部署

### 3.1 源码获取

```bash
# 克隆仓库或下载ZIP包
git clone <repository-url>
cd webgl-3d-editor
```

### 3.2 目录结构

```
webgl-3d-editor/
├── index.html                 # 主入口文件
├── css/
│   └── style.css             # 样式文件
├── js/

│   ├── environment-manager.js # 环境管理

│   └── grid-helper.js        # 网格辅助
├── common/
│   ├── three.min.js          # Three.js核心库
│   ├── OBJLoader.js          # OBJ加载器

    └── ground.jpg             # 地面纹理
```

### 3.3 运行方式

#### 3.3.1 使用本地HTTP服务器(推荐)

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (需安装http-server)
npx http-server -p 8000

# PHP
php -S localhost:8000
```

启动后浏览器访问: `http://localhost:8000`

#### 3.3.2 直接打开(不推荐)

* Chrome: 需添加`--allow-file-access-from-files`启动参数
* Firefox: 可直接打开，但部分功能受限

## 4. 使用说明

### 4.1 首次启动

1. 确保所有文件在正确目录
2. 启动HTTP服务器
3. 访问`http://localhost:8000`
4. 页面显示加载界面，初始化完成后自动进入默认场景

### 4.2 界面布局

* **左侧(350px宽)**: 功能控制面板
  * 场景管理(新建、保存、加载、清空)
  * 光源控制(环境光、点光源、方向光)
  * 相机模式切换(轨道控制、穿梭无人机)
  * 模型管理(加载、添加、变换)
  * 材质编辑(类型、颜色、光泽度、纹理)
  * 场景信息统计
* **中央**: 3D渲染区
  * 左下角: 操作提示(快捷键)
  * 右下角: 状态栏(FPS、模型数、光源数、相机模式)
  * 右上角: 选中模型信息(名称、坐标)

### 4.3 基础操作流程

#### 4.3.1 创建新场景

1. 点击"新建场景"按钮
2. 确认清空当前场景
3. 自动加载默认几何体

#### 4.3.2 添加模型

1. 点击"加载模型"按钮
2. 选择OBJ/GLTF/GLB/FBX文件
3. 在弹窗中设置位置、缩放、旋转参数
4. 点击"确认加载"
5. 模型出现在场景中并自动选中

#### 4.3.3 添加基础几何体

1. 点击"添加几何体"按钮
2. 在提示框中输入类型(cube/sphere/cylinder/cone/torus/plane/octahedron/dodecahedron)
3. 几何体出现在场景中心

#### 4.3.4 操作模型

* **选择**: 左键点击模型
* **拖拽**: 按住左键拖动模型到目标位置(仅在轨道模式下)
* **缩放**: 选中模型后拖动"模型缩放"滑块
* **旋转**: 选中模型后拖动"模型旋转"滑块
* **删除**: 选中后按`Delete`键或点击"删除选中"
* **复制**: 选中后按`Ctrl+D`或点击"复制选中"

#### 4.3.5 光源控制

* **环境光**: 拖动"环境光强度"滑块实时调整
* **添加点光源**: 点击"添加点光源"按钮，在弹窗中设置参数
* **移除点光源**: 点击"移除点光源"按钮(移除最后一个)
* **方向光**: 同上操作

#### 4.3.6 相机控制

* **轨道模式**: 鼠标左键旋转，右键平移，滚轮缩放
* **穿梭无人机模式**:
  * `W/S`: 前进/后退
  * `A/D`: 左移/右移
  * `Q/E`: 下降/上升
  * 鼠标移动: 控制视角(需按住左键)
  * 水平仪限制: 相机最低高度0.5单位

#### 4.3.7 场景保存与加载

* **保存**: 点击"保存场景"，下载JSON文件到本地
* **加载**: 点击"加载场景"，选择之前保存的JSON文件
* **自动保存**: 每30秒自动保存到localStorage(功能待扩展)

### 4.4 高级功能

#### 4.4.1 生成初始场景(情感主题)

1. 点击"生成初始场景"按钮
2. 等待约5-10秒(生成500棵树)
3. 场景出现全家福模型，周围环绕森林
4. 相机自动调整到最佳视角

#### 4.4.2 材质与纹理

* **更改材质**: 选中模型后，从下拉框选择材质类型(Basic/Lambert/Phong/Standard)
* **调整颜色**: 点击"材质颜色"选择器
* **光泽度**: Phong材质下可调整shininess值
* **加载纹理**: 点击"加载纹理"，选择图片文件
* **法线贴图**: 点击"加载法线贴图"，增强表面细节

#### 4.4.3 环境设置

* **天空盒**: 在`environmentManager.js`中配置`setSkybox()`路径
* **地面纹理**: 同上配置`setGroundTexture()`路径
* **雾效**: 在`SceneManager.init()`中调整`Fog`参数

## 6. 模型与资源准备

### 6.1 支持的模型格式

* **OBJ**: 完全支持，需配套MTL文件(自动加载)
* **GLTF/GLB**: 预留接口，需引入`GLTFLoader.js`
* **FBX**: 预留接口，需引入`FBXLoader.js`

### 6.2 模型规范

* **单位**: 建议使用米制单位
* **原点**: 模型原点建议在建模软件中居中
* **材质**: 支持漫反射贴图、法线贴图
* **大小**: 单个模型文件建议不超过50MB
* **三角面**: 控制在10万面以内以保证性能

### 6.3 纹理规范

* **格式**: JPG, PNG (支持透明)
* **尺寸**: 2的幂次方(1024x1024, 2048x2048)
* **色彩空间**: 颜色贴图用sRGB，法线贴图用Linear

### 6.4 资源放置

* **模型文件**: 放入`./model/`或`./models/`目录
* **纹理文件**: 放入`./textures/`目录
* **路径引用**: 代码中使用相对路径，确保HTTP服务器正确映射

## 7. 故障排除

### 7.1 初始化失败

**现象**: 加载界面卡住，显示"初始化失败" **原因**: Three.js库未加载 **解决**: 检查`index.html`中`<script>`标签路径，确保`common/`目录存在

### 7.2 模型加载失败

**现象**: 模型显示为红色立方体 **原因**: 模型文件路径错误或格式不支持 **解决**:

1. 检查浏览器Console错误信息
2. 确认模型文件在`./model/`目录
3. 检查文件名大小写(Linux服务器区分大小写)

### 7.3 性能问题

**现象**: FPS低于30，操作卡顿 **原因**: 模型面数过多或光源数量过大 **解决**:

1. 减少场景模型数量
2. 降低阴影贴图分辨率(`shadow.mapSize`)
3. 关闭阴影`castShadow = false`
4. 使用`toggleLightHelpers(false)`隐藏光源辅助器

### 7.4 跨域问题

**现象**: 加载本地模型时报错"CORS policy" **原因**: 浏览器安全策略限制文件访问 **解决**: 必须使用HTTP服务器运行，不能直接打开文件

### 7.5 UI无法交互

**现象**: 按钮点击无响应 **原因**: JavaScript报错导致 **解决**: 打开Console查看错误堆栈，修复对应代码
