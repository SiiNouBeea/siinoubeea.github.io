# WebGL三维场景渲染器 - 项目详细设计文档

## 版本信息

* **版本**: 1.0
* **最后更新**: 2024年12月
* **技术栈**: WebGL, Three.js r128, JavaScript ES6+

---

## 1. 系统架构设计

### 1.1 整体架构

系统采用分层模块化架构，实现高内聚低耦合设计目标。主控制器`WebGLEditor`统筹各管理器协同工作，各管理器职责单一且可独立扩展。

复制

```
WebGLEditor (应用层)
├── Core Managers (核心管理层)
│   ├── SceneManager        # Three.js场景生命周期管理
│   ├── ModelManager         # 3D模型全生命周期管理
│   ├── LightManager         # 多类型光源系统管理
│   ├── CameraManager        # 多模式相机控制系统
│   └── InteractionManager   # 用户交互事件处理
├── Support Managers (支持管理层)
│   ├── UIManager            # 用户界面状态管理
│   ├── FileManager          # 场景数据持久化
│   ├── EnvironmentManager   # 环境效果管理
│   └── SceneGenerator       # 程序化场景生成
└── Utilities (工具层)
    └── GridHelper           # 3D空间参考辅助
```

### 1.2 核心设计原则

* **单一职责原则**: 每个管理器只负责特定功能域
* **开放封闭原则**: 模块可扩展，但不可修改核心逻辑
* **依赖倒置**: 高层模块不依赖底层Three.js实现细节
* **性能优先**: 采用`requestAnimationFrame`优化渲染，实现帧率自适应

## 2. 核心模块详细设计

### 2.1 主控制器模块 (main.js)

#### 2.1.1 WebGLEditor类

**类定义**: `class WebGLEditor`

**核心职责**: 应用程序入口，协调各管理器初始化与运行时调度

**构造函数**:

**JavaScript**复制

```javascript
constructor() {
    this.sceneManager = null;           // 场景管理器实例
    this.modelManager = null;           // 模型管理器实例
    this.lightManager = null;           // 光源管理器实例
    this.cameraManager = null;          // 相机管理器实例
    this.uiManager = null;              // UI管理器实例
    this.interactionManager = null;     // 交互管理器实例
    this.fileManager = null;            // 文件管理器实例
    this.environmentManager = null;     // 环境管理器实例
    this.sceneGenerator = null;         // 场景生成器实例
  
    // 性能监控
    this.clock = new THREE.Clock();     // 高精度时间源
    this.frameCount = 0;                // 帧计数器
    this.lastTime = 0;                  // 上次采样时间戳
    this.fps = 0;                       // 实时帧率
  
    // 应用状态
    this.isInitialized = false;         // 初始化标志
    this.selectedModel = null;          // 当前选中模型
    this.scenePath = [];                // 场景路径栈(预留)
  
    this.init(); // 自动启动初始化
}
```

**核心方法**:

##### `async init()`

* **功能**: 完整的应用初始化流程，按依赖顺序初始化各管理器
* **调用序列**:
  1. `showLoadingOverlay('正在初始化WebGL引擎...')`
  2. 实例化`SceneManager`并等待`init()`
  3. 实例化`LightManager`, `CameraManager`, `ModelManager`, `InteractionManager`, `FileManager`, `UIManager`, `EnvironmentManager`
  4. 实例化`SceneGenerator`
  5. 调用`setupDefaultScene()`创建默认场景
  6. 启动`animate()`主循环
* **异常处理**: 捕获所有初始化错误，显示红色错误提示
* **返回值**: `Promise<void>`

##### `async setupDefaultScene()`

* **功能**: 创建包含基础光照和几何体的默认场景
* **执行逻辑**:
  1. 调用`environmentManager.createDefaultEnvironment()`
  2. 添加环境光(强度0.3)和方向光(强度1.0)
  3. 在X轴-3, 0, 3位置分别添加红色立方体、青色球体、蓝色圆柱体
  4. 调用`updateSceneInfo()`刷新UI
* **返回值**: `Promise<void>`

##### `animate()`

* **功能**: 主渲染循环，使用`requestAnimationFrame`实现60FPS渲染
* **核心算法**:
  **JavaScript**复制

  ```javascript
  // FPS计算算法
  const currentTime = performance.now();
  if (currentTime - this.lastTime >= 1000) {
      this.fps = Math.round((this.frameCount * 1000) / (currentTime - this.lastTime));
      this.frameCount = 0;
      this.lastTime = currentTime;
      this.updateStatusBar();
  }
  ```
* **每帧任务**:

  1. 计算`deltaTime`用于帧率标准化
  2. 更新`cameraManager.update(delta)`
  3. 更新`interactionManager.update(delta)`
  4. 调用`sceneManager.render()`渲染场景
* **性能优化**: 使用`this.clock.getDelta()`保证动画速度一致性

##### `updateStatusBar()`

* **功能**: 更新底部状态栏实时信息
* **更新内容**:
  * FPS计数
  * 模型总数(`modelManager.getModelCount()`)
  * 光源总数(`lightManager.getTotalLightCount()`)
  * 当前相机模式(`cameraManager.getCurrentMode()`)

##### `updateSceneInfo()`

* **功能**: 更新右侧场景信息面板
* **更新内容**:
  * 已加载模型数
  * 当前选中模型名称
  * 点光源/方向光数量
  * 相机实时坐标(保留1位小数)

##### `showLoadingOverlay(message)`

* **参数**: `message {String}` - 加载提示文本
* **功能**: 显示全屏半透明遮罩，阻止用户操作
* **DOM操作**: 修改`#loading-overlay`的`display`样式为`flex`

##### `hideLoadingOverlay()`

* **功能**: 隐藏加载遮罩
* **DOM操作**: 设置`#loading-overlay`的`display`为`none`

##### `showError(message)`

* **参数**: `message {String}` - 错误信息
* **功能**: 在加载遮罩上显示红色错误文本
* **样式**: 设置文字颜色为`#ff6b6b`

##### `async newScene()`

* **功能**: 创建全新空白场景
* **实现**: 调用`clearAllModels()`和`clearAllLights()`后执行`setupDefaultScene()`

##### `async clearScene()`

* **功能**: 清空当前所有场景内容
* **用户确认**: 调用`confirm()`防止误操作
* **清理范围**: 所有模型、光源、选中状态

##### `selectModel(model)`

* **参数**: `model {THREE.Object3d|null}` - 要选中的模型对象
* **功能**: 管理模型选中状态，更新视觉高亮
* **视觉反馈**: 选中模型添加青色(`#4ecdc4`)自发光效果，强度0.2
* **UI同步**: 调用`showSelectedModelInfo()`或`hideSelectedModelInfo()`

##### `showSelectedModelInfo(model)`

* **参数**: `model {THREE.Object3d}` - 选中模型
* **功能**: 在右上角显示模型详细信息面板
* **显示内容**: 模型名称、X/Y/Z坐标(保留2位小数)

##### `hideSelectedModelInfo()`

* **功能**: 隐藏模型信息面板

##### `updateModelAppearance(model)`

* **参数**: `model {THREE.Object3d}` - 目标模型
* **功能**: 更新模型材质以反映选中状态
* **实现细节**:
  * 遍历模型所有`isMesh`子对象
  * 选中时: 克隆材质并设置`emissive = new THREE.Color(0x4ecdc4)`, `emissiveIntensity = 0.2`
  * 取消选中时: 恢复`userData.originalMaterial`

##### `getSelectedModel()`

* **返回值**: `{THREE.Object3d|null}` - 当前选中模型
* **功能**: 提供模型访问接口

##### `exportImage()`

* **功能**: 触发场景截图导出
* **实现**: 委托给`sceneManager.exportToImage()`

### 2.2 场景管理模块 (main.js)

#### 2.2.1 SceneManager类

**类定义**: `class SceneManager`

**核心职责**: 封装Three.js场景、相机、渲染器，提供渲染服务

**构造函数**:

**JavaScript**复制

```javascript
constructor(canvasId) {
    this.canvas = document.getElementById(canvasId);  // WebGL画布DOM
    this.scene = null;                                // Three.js场景实例
    this.camera = null;                               // 透视相机实例
    this.renderer = null;                             // WebGL渲染器实例
    this.controls = null;                             // 轨道控制器实例
    this.raycaster = new THREE.Raycaster();           // 射线检测器
    this.mouse = new THREE.Vector2();                 // 标准化鼠标坐标
}
```

**核心方法**:

##### `async init()`

* **功能**: 初始化Three.js核心组件
* **初始化步骤**:
  1. **场景创建**: `new THREE.Scene()`，背景色`#1a1a2e`，雾效`Fog`范围10-100
  2. **相机创建**: `PerspectiveCamera(75, aspect, 0.1, 1000)`，初始位置(0,5,15)
  3. **渲染器创建**: `WebGLRenderer({antialias: true, preserveDrawingBuffer: true})`，启用阴影`PCFSoftShadowMap`
  4. **控制器创建**: `OrbitControls`，启用阻尼`dampingFactor=0.05`
  5. **地面创建**: 100x100平面，半透明蓝色材质，接收阴影
  6. **事件监听**: 窗口大小变化自适应
* **性能配置**: `setPixelRatio(Math.min(window.devicePixelRatio, 2))`防止高DPI设备性能浪费

##### `createGround()`

* **功能**: 创建场景地面
* **几何体**: `PlaneGeometry(100, 100)`
* **材质**: `MeshLambertMaterial`，颜色`#2d3561`，透明度0.8
* **变换**: 旋转`-Math.PI/2`，Y轴偏移-2

##### `onWindowResize()`

* **功能**: 响应式布局处理
* **操作**: 更新相机aspect比，重新设置渲染器尺寸

##### `render()`

* **功能**: 执行单帧渲染
* **调用**: `renderer.render(scene, camera)`

##### `addToScene(object)`

* **参数**: `object {THREE.Object3d}` - 要添加的对象
* **功能**: 安全添加对象到场景

##### `removeFromScene(object)`

* **参数**: `object {THREE.Object3d}` - 要移除的对象
* **功能**: 从场景图中移除对象

##### `exportToImage()`

* **功能**: 导出当前视图为PNG图像
* **技术**: `renderer.domElement.toDataURL('image/png')`
* **交互**: 自动创建`<a>`元素触发下载，文件名带时间戳

### 2.3 模型管理模块 (model-manager.js)

#### 2.3.1 ModelManager类

**类定义**: `class ModelManager`

**核心职责**: 管理3D模型的完整生命周期，包括创建、加载、变换、材质编辑

**构造函数**:

**JavaScript**复制

```javascript
constructor(sceneManager) {
    this.sceneManager = sceneManager;          // 场景管理器引用
    this.models = [];                          // 模型对象数组
    this.selectedModel = null;                 // 当前选中模型
    this.modelIdCounter = 0;                   // ID生成计数器
    this.supportedFormats = ['.obj', '.gltf', '.glb', '.fbx']; // 支持格式
    this.defaultMaterial = new THREE.MeshPhongMaterial({     // 默认材质
        color: 0x4ecdc4,
        shininess: 30,
        specular: 0x111111
    });
}
```

**核心方法**:

##### `generateModelId(type = 'model')`

* **参数**: `type {String}` - 模型类型前缀
* **返回值**: `{String}` - 唯一标识符，格式`类型_计数器_时间戳`
* **实现**: `return `{type}\_** **{++this.modelIdCounter}\_\${Date.now()}\`\`;\`

##### `async addPrimitive(type, options = {})`

* **参数**:
  * `type {String}` - 几何体类型(cube/sphere/cylinder/cone/torus/plane/octahedron/dodecahedron)
  * `options {Object}` - 配置项{position, scale, rotation, color, name}
* **返回值**: `Promise<THREE.Object3d>` - 创建的网格对象
* **功能**: 创建基础几何体模型
* **实现逻辑**:
  1. 根据`type`创建对应`BufferGeometry`
  2. 克隆默认材质并设置颜色
  3. 创建`Mesh`，应用位置/缩放/旋转变换
  4. 启用阴影(castShadow=true, receiveShadow=true)
  5. 设置`userData`包含id, name, type, primitiveType等信息
  6. 添加到场景和`models`数组
  7. **自动选中**新模型

##### `async loadModel(file, options = {})`

* **参数**:
  * `file {File}` - 用户选择的模型文件
  * `options {Object}` - 加载配置{position, scale, rotation, name}
* **返回值**: `Promise<THREE.Object3d>`
* **功能**: 加载外部模型文件
* **格式支持**: OBJ(完整支持), GLTF/GLB/FBX(预留接口)
* **实现逻辑**:
  1. 验证文件扩展名在`supportedFormats`中
  2. 使用`THREE.OBJLoader.loadAsync()`异步加载
  3. 遍历模型子对象启用阴影
  4. 应用变换参数
  5. 设置`userData`包含文件名、类型等信息
  6. 添加到场景和`models`数组
  7. **自动选中**新模型

##### `selectModel(model)`

* **参数**: `model {THREE.Object3d|null}` - 目标模型
* **功能**: 切换模型选中状态
* **视觉反馈**:
  * 取消原选中模型的`userData.isSelected`标志
  * 为新模型设置`userData.isSelected = true`
  * 调用`updateModelAppearance()`更新材质
* **UI同步**: 通过`window.webglEditor.selectModel()`通知主控制器

##### `updateModelAppearance(model)`

* **参数**: `model {THREE.Object3d}` - 需要更新外观的模型
* **功能**: 根据选中状态切换材质效果
* **算法**:
  **JavaScript**复制

  ```javascript
  model.traverse((child) => {
      if (child.isMesh && child.material) {
          if (model.userData.isSelected) {
              // 高亮效果
              const highlightMaterial = child.material.clone();
              highlightMaterial.emissive = new THREE.Color(0x4ecdc4);
              highlightMaterial.emissiveIntensity = 0.2;
              child.material = highlightMaterial;
          } else {
              // 恢复原始材质
              if (child.userData.originalMaterial) {
                  child.material = child.userData.originalMaterial.clone();
                  delete child.userData.originalMaterial;
              }
          }
      }
  });
  ```

##### `updateSelectedModel(options = {})`

* **参数**: `options {Object}` - 更新项{position, scale, rotation, color}
* **功能**: 实时更新选中模型的变换属性
* **安全限制**:
  * 缩放值限制在0.01-100之间，防止极端值导致渲染异常
  * 旋转角度从度转换为弧度
* **UI反馈**: 如果模型正在显示信息面板，同步更新位置显示

##### `deleteSelectedModel()`

* **功能**: 删除当前选中模型
* **安全机制**: 无模型选中时输出警告并返回false
* **清理流程**:
  1. `selectModel(null)`取消选中
  2. 从`models`数组中` splice(index, 1)`
  3. `sceneManager.removeFromScene()`从场景移除
  4. 调用`updateSceneInfo()`刷新UI
* **返回值**: `{Boolean}` - 删除成功返回true

##### `duplicateSelectedModel()`

* **功能**: 复制选中模型
* **实现策略**:
  * 几何体模型: 使用`clone()`深拷贝，X轴偏移2单位避免重叠
  * 外部模型: 同样使用`clone()`，保留文件引用信息
* **命名规则**: 原名称 + `_副本`
* **返回值**: `{THREE.Object3d|null}` - 新模型对象

##### `async clearAllModels()`

* **功能**: 清空场景中所有模型
* **实现**: 遍历`models`数组，逐个调用`sceneManager.removeFromScene()`
* **后置**: `this.models = []`, `this.selectedModel = null`

##### `getModelsData()`

* **返回值**: `{Array<Object>}` - 模型序列化数据数组
* **功能**: 收集所有模型数据用于场景保存
* **数据结构**:
  **JavaScript**复制

  ```javascript
  {
      id: "cube_1_1703864400000",
      name: "cube_1",
      type: "primitive",
      primitiveType: "cube",
      position: {x, y, z},
      scale: {x, y, z},
      rotation: {x, y, z}, // 度为单位
      color: 0xff6b6b
  }
  ```
* **外部模型额外字段**: `fileName`, `originalPath`

##### `async loadModelsFromData(modelsData, fileMappings = {})`

* **参数**:
  * `modelsData {Array<Object>}` - 模型数据数组
  * `fileMappings {Object}` - 外部模型文件路径映射
* **功能**: 从序列化数据重建场景
* **流程**:
  1. `clearAllModels()`清空现有
  2. 遍历`modelsData`，根据`type`字段分支处理
  3. 几何体: 调用`addPrimitive()`
  4. 外部模型: 调用`loadExternalModelFromData()`

##### `async loadExternalModelFromData(modelData, fileMappings)`

* **参数**:
  * `modelData {Object}` - 单个模型数据
  * `fileMappings {Object}` - 文件路径映射表
* **功能**: 智能加载外部模型文件
* **文件查找策略**:
  1. 优先使用`fileMappings[modelData.id]`中的路径
  2. 尝试标准路径: `./model/`, `./models/`, `./assets/`
  3. 使用`checkFileExists()`验证文件存在性
* **容错机制**: 文件不存在时创建红色立方体占位符

### 2.4 光源管理模块 (light-manager.js)

#### 2.4.1 LightManager类

**类定义**: `class LightManager`

**核心职责**: 管理五种光源类型，实现动态添加、删除、参数调整及阴影配置

**构造函数**:

**JavaScript**复制

```javascript
constructor(sceneManager) {
    this.sceneManager = sceneManager;
    this.ambientLights = [];      // 环境光数组
    this.directionalLights = [];  // 方向光数组
    this.pointLights = [];        // 点光源数组
    this.spotLights = [];         // 聚光灯数组
    this.areaLights = [];         // 面光源数组(新增)
  
    // 默认强度配置
    this.defaultAmbientIntensity = 0.3;
    this.defaultDirectionalIntensity = 1.0;
    this.defaultPointIntensity = 1.0;
    this.defaultAreaIntensity = 2.0;
}
```

**核心方法**:

##### `addAmbientLight(intensity = 0.3, color = 0xffffff)`

* **参数**:
  * `intensity {Number}` - 光照强度0-1
  * `color {Number|String}` - 16进制颜色值
* **返回值**: `{THREE.AmbientLight}` - 环境光对象
* **特性**: 无方向性，不产生阴影，提供基础照明
* **实现**: 创建`AmbientLight`，设置`userData`存储元数据，推入`ambientLights`数组

##### `addDirectionalLight(intensity = 1.0, color = 0xffffff, position = {x:10,y:10,z:5})`

* **参数**: `position` - 光源位置(影响方向)
* **返回值**: `{THREE.DirectionalLight}` - 方向光对象
* **阴影配置**:
  * `mapSize = 2048x2048` 高分辨率阴影贴图
  * `camera`范围: left=-20, right=20, top=20, bottom=-20, near=0.1, far=50
* **辅助器**: 创建`DirectionalLightHelper`可视化光线方向

##### `addPointLight(intensity = 1.0, color = 0xffffff, position = {x:0,y:5,z:0}, distance = 0, decay = 2)`

* **参数**:
  * `distance {Number}` - 衰减距离，0表示无限远
  * `decay {Number}` - 衰减系数，物理光照模型中为2
* **返回值**: `{THREE.PointLight}` - 点光源对象
* **特性**: 全向发光，支持距离衰减
* **阴影配置**: `mapSize = 1024x1024`

##### `addSpotLight(intensity = 1.0, color = 0xffffff, position = {x:0,y:10,z:0}, target = {x:0,y:0,z:0})`

* **参数**: `target {Object}` - 照射目标点
* **返回值**: `{THREE.SpotLight}` - 聚光灯对象
* **默认参数**:
  * `angle = Math.PI / 6` (30度锥角)
  * `penumbra = 0.1` (半影区)
  * `distance = 30` (最大距离)
* **辅助器**: `SpotLightHelper`显示锥形光照范围

##### `addAreaLight(intensity = 2.0, color = 0xffffff, position = {x:0,y:5,z:0}, distance = 20)`

* **返回值**: `{THREE.RectAreaLight}` - 面光源对象
* **特性**: 矩形区域柔和照明，需要`RectAreaLightHelper`
* **技术限制**: Three.js中面光源不产生阴影
* **实现**: 创建`RectAreaLight`，尺寸`distance x distance`，推入`areaLights`

##### `removePointLight() / removeDirectionalLight() / removeSpotLight() / removeAreaLight()`

* **功能**: 从对应数组弹出最后一个光源并清理
* **清理流程**:
  1. `array.pop()`获取光源对象
  2. 如果存在`helper`，从场景移除
  3. 从场景移除光源本体

  const forward = new THREE.Vector3();
  camera.getWorldDirection(forward);
  forward.y = 0; // 保持水平移动
  forward.normalize();

  right.crossVectors(forward, new THREE.Vector3(0, 1, 0));

## 3. 核心算法与性能优化

### 3.1 性能监控算法

**FPS计算**: 每秒采样一次，计算`frameCount / (currentTime - lastTime) * 1000`

### 3.2 帧率标准化移动

**穿梭无人机模式**: `moveSpeed * deltaTime * 60`确保不同帧率下移动速度一致

### 3.3 射线检测优化

**交互管理器**: `intersectObjects(objects, true)`第二个参数启用递归，支持检测模型子对象

### 3.4 材质克隆策略

**选中高亮**: 克隆材质而非直接修改，避免污染原始材质，支持取消选中时恢复

### 3.5 错误降级机制

**模型加载**: 自动切换到占位符，保证应用不崩溃，提供视觉反馈

## 4. 接口设计规范

### 4.1 异步接口

所有涉及文件IO、模型加载的操作均返回`Promise`，支持`async/await`语法

### 4.2 事件系统

UI事件采用回调函数模式，Three.js事件(如窗口大小)使用标准事件监听

### 4.3 数据接口

场景数据采用JSON格式，版本号`version`字段保证向前兼容性
